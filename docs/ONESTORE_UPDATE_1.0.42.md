# 잠깐, 할 일 1.0.42 업데이트 설명

## 원스토어 업데이트 내용

- Google 계정 로그인을 통한 할 일 동기화 기능을 추가했습니다.
- 서버 저장 상태 화면을 추가해 Firestore에 저장된 메모 개수와 최근 저장 시간을 확인할 수 있게 했습니다.
- 잠금화면에서 음성 입력을 사용할 수 있게 개선했습니다.
- 음성 입력 중 잠깐 말을 멈춰도 바로 종료되지 않도록 대기 시간을 늘렸습니다.
- 잠금화면을 닫은 뒤 다시 즉시 나타나는 문제를 줄였습니다.
- 설정 화면 구조를 정리해 음성 입력, 서버 동기화, 권한/배터리, 언어/표시, 문제 해결 항목을 더 쉽게 찾을 수 있게 했습니다.
- 앱 아이콘과 알림 아이콘을 새 디자인에 맞게 변경했습니다.
- 앱 전체 포인트 컬러와 일부 버튼/체크박스 디자인을 정리했습니다.
- 메모리 사용과 배터리 효율을 위해 중복 예약 작업, 센서 감지, 진단 로그 처리를 개선했습니다.

## 짧은 버전

Google 계정 동기화, 잠금화면 음성 입력, 서버 저장 상태 확인 기능을 추가했습니다. 설정 화면과 아이콘 디자인을 정리하고, 잠금화면 재등장 문제 및 배터리/메모리 효율을 개선했습니다.
